# چک‌لیست پیش از انتشار (بازار / مایکت) — دُردانه

مالک: **AI-15**. هیچ نسخه‌ای بدون تیک خوردن **همه‌ی** موارد الزامی (⛔) منتشر نمی‌شود.
هر شکست = گزارش باگ با شدت طبق `qa/severity-policy.md`.

## ۰) پیش‌نیاز خودکار (CI باید سبز باشد)
- [ ] ⛔ `npm run build && npm test` روی main سبز
- [ ] ⛔ همه‌ی contract-testها روی **پکیج‌های واقعی** (نه mock) سبز
- [ ] ⛔ E2E سناریوهای طلایی سبز (پس از RFC-0003)
- [ ] ⛔ `node qa/tools/i18n-lint.mjs` → exit 0 (بدون رشته‌ی هاردکد فارسی)
- [ ] ⛔ اسکن axe بدون خطای serious/critical

## ۱) نصب تمیز (Clean Install)
- [ ] ⛔ نصب APK روی دستگاه بدون نسخه‌ی قبلی → باز شدن < ۳ ثانیه، بدون کرش
- [ ] ⛔ آنبوردینگ کامل تا اولین برد < ۶۰ ثانیه، **بدون تبلیغ/paywall/فرم ثبت‌نام**
- [ ] پازل روزانه‌ی صحیح برای تاریخ تهرانِ دستگاه نمایش داده شود

## ۲) به‌روزرسانی از نسخه‌ی قبلی (Update Path)
- [ ] ⛔ نصب نسخه‌ی منتشرشده‌ی قبلی → بازی + streak بسازید → آپدیت روی آن
- [ ] ⛔ پس از آپدیت: streak، آمار، تم، و پازل نیمه‌کاره **دست‌نخورده**
- [ ] هیچ migration خطایی در logcat

## ۳) آفلاین (خط قرمز ۱۸)
- [ ] ⛔ حالت پرواز → اپ باز می‌شود، پازل روزانه بازی می‌شود، برد ثبت می‌شود
- [ ] ⛔ هیچ toast/dialog «خطای شبکه» در جریان بازی آفلاین
- [ ] بازگشت آنلاین → صف آنالیتیکس بدون duplicate ارسال شود

## ۴) مرز نیمه‌شب تهران (پرریسک‌ترین)
- [ ] ⛔ دستگاه با ساعت ۲۳:۵۵ تهران: بازی، عبور از نیمه‌شب → پازل جدید + streak صحیح
- [ ] ⛔ Timezone دستگاه غیرتهران (مثلاً UTC): puzzleNumber همچنان بر مبنای تهران

## ۵) اشتراک‌گذاری و دیپ‌لینک
- [ ] ⛔ متن اشتراک بدون اسپویل، شماره‌ی پازل **با ارقام فارسی**
- [ ] ⛔ دیپ‌لینک دعوت روی دستگاه بدون اپ → استور؛ با اپ → صفحه‌ی درست
- [ ] اشتراک در تلگرام/واتساپ/ایتا رندر سالم (ایموجی‌ها نشکنند)

## ۶) حجم، مجوزها، امنیت
- [ ] ⛔ حجم APK/AAB ≤ سقف مصوب (بودجه‌ی حجم Master Plan)
- [ ] ⛔ مجوزهای مانیفست = حداقلِ لازم (بدون CONTACTS/SMS/LOCATION)
- [ ] ⛔ هیچ کلید/secret در APK (بازرسی strings)
- [ ] targetSdk مطابق الزام جاری بازار/مایکت

## ۷) پایداری — ۱۰ دقیقه بازی بدون کرش
- [ ] ⛔ روی ≥۳ دستگاه ماتریس (رده‌پایین/میان‌رده/پرچمدار — `qa/device-matrix.md`):
      ۱۰ دقیقه بازی پیوسته (روزانه + تمرین + آلبوم + تنظیمات) → **صفر کرش/ANR**
- [ ] چرخش صفحه، رفتن به پس‌زمینه و بازگشت → state حفظ شود
- [ ] مصرف حافظه ثابت بماند (بدون رشد خطی = نشت)

## ۸) پرداخت (در صورت فعال بودن)
- [ ] ⛔ خرید sandbox بازار/مایکت کامل شود و کالا تحویل گردد
- [ ] لغو در میانه‌ی خرید → بدون کسر، بدون قفل UI

## ۹) نهایی
- [ ] نسخه (versionCode/versionName) درست و یکتا
- [ ] یادداشت انتشار فارسی آماده
- [ ] برچسب git `vX.Y.Z` زده شد
