# ماتریس دستگاه‌های هدف بازار ایران — دُردانه

مالک: **AI-15**. مبنا: اندروید ۸ تا ۱۵، RAM ۲ تا ۱۲GB، WebView Chrome ≥ 90
(الزام Capacitor). تست دستی release طبق `qa/release-checklist.md` حداقل روی
یک دستگاه از هر **رده** اجرا می‌شود.

## پارامترهای عرضی (روی هر رده حداقل یک‌بار)
- **عرض صفحه‌ی ۳۲۰px** (نمایشگر کوچک/بزرگ‌نمایی سیستم) → بدون سرریز افقی RTL
- **فونت سیستم بزرگ (۱.۳×)** → بدون بریدگی متن فارسی
- **حالت تیره‌ی سیستم** ↔ تم اپ
- **WebView**: نسخه از `chrome://webview` — کف پشتیبانی **Chrome 90**؛ روی
  اندروید ۸–۹ اغلب باید از Play/بازار آپدیت شود → سناریوی WebView قدیمی تست شود
  (پیام راهنمای آپدیت، نه کرش)
- **بدون GMS** (هواوی/آنر) → نصب از بازار/مایکت، دیپ‌لینک، پرداخت درون‌برنامه‌ای بازار

## راهنمای اجرای تست دستی
1. دستگاه را به Wi-Fi وصل، ساعت خودکار **خاموش** (برای سناریوی نیمه‌شب).
2. `qa/release-checklist.md` را از بالا به پایین اجرا کنید؛ هر شکست → گزارش با
   قالب `qa/reports/BUG-TEMPLATE.md` + مدل دستگاه/اندروید/WebView در گزارش.
3. logcat را در کل جلسه ضبط کنید: `adb logcat -v time > logs/<device>-<date>.txt`
4. برای رده‌پایین ۲GB: در میانه‌ی بازی ۳ اپ سنگین باز کنید و برگردید → state سالم.
