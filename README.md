## 🎮 بازی در یک نگاه

- **ژانر:** معمای کلمات روزانه (Word Puzzle) — فرمت اثبات‌شده‌ی Daily + Streak + Share
- **تمایز ضدکلون:** «کارت فرهنگی» — ضرب‌المثل، شعر و دانستنی‌های فرهنگ ایرانی پس از حل معما
- **مخاطب:** کژوال ۱۸–۴۵ سال، با تمرکز بر زنان و میان‌سالان (مخاطب طلایی کم‌رقیب بازار ایران)
- **پلتفرم انتشار:** کافه‌بازار + مایکت (اندروید) + نسخه‌ی وب (موتور وایرال بی‌اصطکاک)
- **مدل درآمد:** اخلاقی — تبلیغ جایزه‌ای اختیاری + خرید «بدون تبلیغ» + بسته‌های محتوایی + تم‌ها. **هرگز pay-to-win.**

## 🏗️ پشته‌ی فنی

- **هسته و رابط کاربری:** TypeScript + Preact + Vite (PWA کامل)
- **بسته‌بندی اندروید:** Capacitor (خروجی AAB/APK برای بازار/مایکت)
- **بک‌اند:** Hono + Cloudflare Workers + D1 (لیدربورد، معمای روزانه، دوئل)
- **مونوریپو:** npm workspaces — هر AI مالک یک پکیج

## 🚀 شروع سریع (برای همه‌ی AIها)

```bash
git clone <repo> && cd <repo>
npm ci            # نصب قطعی از package-lock (فقط AI-14 حق commit لاک را دارد)
npm run build     # build همه‌ی workspaceها — باید سبز باشد
npm test          # تست همه — contracts پوشش ۱۰۰٪
npm run lint      # ESLint سخت‌گیر (no-any)

# ⚠️ و مهم‌تر از همه: اپ مونتاژشده را با چشم خودتان ببینید
npm run build:app
npx vite preview --port 3000   # سپس در ویوپورت گوشی (۴۱۲×۹۰۰) بازش کنید
```

- شاخه‌ی کاری: `ai-XX/<feature>` — گارد مالکیت CI فقط مسیرهای خودتان را می‌پذیرد (`tools/check-ownership.mjs`).
- بودجه‌ی حجم: وب < 2MB gzip، AAB < 30MB (`tools/check-budget.mjs`).
- وابستگی جدید یا تغییر contracts: فقط با RFC — [`docs/rfcs/TEMPLATE.md`](docs/rfcs/TEMPLATE.md) + [`docs/deps-policy.md`](docs/deps-policy.md).
- ✅ ورک‌فلوهای CI/CD فعال‌اند: [`.github/workflows/`](.github/workflows/) — `ci.yml` (لینت/تست/بیلد)، `apk-debug.yml` (APK دیباگ)، `release.yml` (APK+AAB امضاشده).
- ⚠️ **APK فقط و فقط در GitHub Actions ساخته می‌شود، هرگز در محیط توسعه** (Gradle+R8 به ۲–۳GB RAM نیاز دارد).
- راهنمای انتشار اندروید: [`native/README.md`](native/README.md)
