# RFC-0008 — افزودن وابستگی preact برای صفحه‌های UI

- **نویسنده:** AI-08
- **تاریخ:** 2026-08-22
- **وضعیت:** 🟡 در انتظار بررسی
- **نوع:** وابستگی جدید

## مشکل

قرارداد (§6) دو صفحه‌ی `StatsScreen` (/stats) و `AlbumScreen` (/album) را به مالکیت
`packages/meta-retention` سپرده و `tsconfig.base.json` کل مونوریپو را روی
`jsx: react-jsx` با `jsxImportSource: preact` قفل کرده است. یعنی معماری از روز اول
Preact را فرض کرده، اما پکیج `preact` هنوز در `package.json` ریشه/ورک‌اسپیس‌ها pin
نشده است. بدون آن:

- کامپوننت‌های `.tsx` قابل build با تایپ‌های واقعی نیستند؛
- در `meta-retention` فعلاً یک شیم موقتِ فقط-تایپ (`src/preact-shim.d.ts`) این خلأ را
  پر می‌کند که باید پس از تأیید این RFC حذف شود.

## پیشنهاد

- **پکیج:** `preact`
- **نسخه‌ی pin:** `10.24.3` (دقیق، بدون `^` — مطابق deps-policy)
- **حجم:** ~**4.6KB gzip** هسته (+ ~1.5KB برای `preact/hooks`) — منبع: bundlephobia
- **وابستگی‌های transitive:** **صفر** (preact هیچ dependency در زمان اجرا ندارد)
- **محل نصب:** `dependencies` ریشه‌ی مونوریپو (hoist شده برای همه‌ی پکیج‌های UI:
  app-shell، game-board، ui-kit، meta-retention و…)

اثر روی بودجه‌ی باندل meta-retention (≤150KB gzip): ناچیز — preact بین همه‌ی
پکیج‌های UI مشترک است و فقط یک‌بار در باندل نهایی می‌آید.

## جایگزین بدون‌وابستگی بررسی‌شده

1. **Vanilla DOM:** با دو صفحه‌ی تعاملی (تقویم شمسی با ناوبری ماه، مودال کارت، گرید
   دستاورد) کد imperative شکننده و غیرقابل‌اشتراک با بقیه‌ی UI اپ می‌شود؛ ضمناً بقیه‌ی
   پکیج‌های UI طبق tsconfig پایه Preact-محورند — دو پارادایم موازی یعنی نقض یکپارچگی.
2. **ادامه با شیم تایپی:** فقط تایپ می‌دهد نه runtime؛ اپ نهایی بدون preact واقعی
   اصلاً اجرا نمی‌شود. شیم راه‌حل موقتِ «توسعه‌ی موازی بدون بلاک‌شدن» بود (خط قرمز ۲:
   آداپتور موقت در ماژول خودت)، نه جایگزین دائمی.
3. **React:** ~44KB gzip یعنی ~۸ برابر preact با همان API — خلاف اصل «سبک‌وزن اول».

## پکیج‌های متأثر

- `packages/meta-retention` (StatsScreen، AlbumScreen، MosaicTile) — پس از تأیید،
  `src/preact-shim.d.ts` حذف می‌شود.
- عملاً همه‌ی پکیج‌های دارای UI (app-shell، game-board، ui-kit) که با همین فرض
  `jsxImportSource: preact` نوشته می‌شوند از همین pin استفاده خواهند کرد.

## مهاجرت

تغییری در contracts یا API عمومی نیست. پس از merge:
1. مالک ریشه (AI-01/AI-05) `preact@10.24.3` را به `dependencies` ریشه اضافه و
   `package-lock.json` را به‌روز می‌کند (فقط مالک ریشه — خط قرمز lockfile).
2. AI-08 شیم `preact-shim.d.ts` را حذف و import ها را بدون تغییر نگه می‌دارد
   (شیم عمداً API-سازگار با preact واقعی نوشته شده).
