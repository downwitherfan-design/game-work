# RFC-0015 — بازطراحی بصری کامل به سبک «آمیرزا» (Amirza-style Visual Overhaul)

- **نویسنده:** AI Design Director (مدیر گرافیک ارشد پروژه)
- **تاریخ:** 2026-08-29
- **وضعیت:** ✅ در حال اجرا (تأیید مدیر پروژه دریافت شد)
- **شاخه:** `ai-04/gui-amirza-style`

## مشکل

GUI فعلی دُردانه (توکن‌های پایه + تایل‌های flat مربع + پس‌زمینه‌ی خاکستری) از نظر بصری «شبیه
هزار تا Wordle-clone دیگر» است و از هویت گرم، ایرانی و کارتونی‌ای که بازار هدف
(کافه‌بازار/مایکت) انتظار دارد فاصله دارد. رقبای موفق مثل **آمیرزا** با بیش از ۱۰ میلیون
نصب، هویت بصری قوی دارند: کاشی چوبی سه‌بعدی، حروف طلایی برجسته، پس‌زمینه‌ی نقاشی‌شده
از معماری ایرانی، دکمه‌های گنبدی و شخصیت‌های کارتونی.

## پیشنهاد

بازطراحی کامل لایه‌ی presentation در سه پکیج UI بدون تغییر منطق بازی، بدون تغییر
قرارداد `@dordaneh/contracts` و بدون تغییر رابط عمومی پکیج‌ها:

1. **ui-kit/tokens.css** — اضافه‌کردن توکن‌های مشتق برای گرادیان چوب/طلا/پارچه، سایه‌های
   سه‌بعدی، پس‌زمینه‌های SVG. مقادیر پایه‌ی قرارداد (`--dor-correct` و…) دست‌نخورده.
2. **ui-kit/ui-kit.css** — کاشی‌های چوبی سه‌بعدی، دکمه‌های گنبدی، بنر ریبون، کارت کاشی‌کاری.
3. **app-shell/shell.css** — پس‌زمینه‌ی صحنه‌ی ایرانی، هدر ریبون، ناوبری پایین چوبی.
4. **game-board/styles.ts** — تخته و کیبورد به سبک آمیرزا.
5. **دارایی‌های SVG** — یک SVG پس‌زمینه‌ی صحنه (< 20KB) در `ui-kit/src/assets/`.

## استثناهای قوانین (تأیید مدیر پروژه)

- خط قرمز ۲۵ (رنگ‌های hex هاردکد ممنوع): این RFC اجازه‌ی افزودن hex در فایل‌های توکن
  `tokens.css` را می‌دهد (چون آنجا محل تعریف توکن است، نه مصرف). سایر فایل‌ها همچنان
  فقط از var(--dor-*) استفاده می‌کنند.
- خط قرمز ۱ (مالکیت کد): این PR به‌صورت استثنایی به سه پکیج UI هم‌زمان دست می‌زند
  (ui-kit + app-shell + game-board). چون تغییرات کاملاً بصری و coordinated هستند و
  رابط عمومی هیچ پکیجی تغییر نمی‌کند، مدیر پروژه مجوز داده است.

## پکیج‌های متأثر

- `packages/ui-kit/` (توکن‌ها + کامپوننت‌ها + assets)
- `packages/app-shell/` (shell.css فقط)
- `packages/game-board/` (styles.ts فقط)

## چیزی که تغییر نمی‌کند

- منطق بازی (core-engine)
- قراردادها (`@dordaneh/contracts`)
- API عمومی هر پکیج (props، exports)
- رشته‌های متنی UI (locales/fa.json)
- بودجه‌ی حجم: کل تغییرات < 30KB gzip اضافه

## مهاجرت

هیچ. تغییرات کاملاً بصری، بدون breaking change.
