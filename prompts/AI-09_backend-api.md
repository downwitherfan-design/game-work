## 🎯 مأموریت تو

### ۱) پشته
**Hono + Cloudflare Workers/Pages Functions + D1 (SQLite)** — رایگان تا مقیاس بزرگ، بدون نگهداری سرور، latency پایین. `wrangler.jsonc` و `migrations/` داخل پکیج خودت.

### ۲) پیاده‌سازی کامل REST قرارداد (بخش ۷)
- `GET /daily/:puzzleNumber/meta` → checksum (صحت‌سنجی جواب آفلاین کلاینت).
- `POST /result` → ثبت نتیجه‌ی ناشناس + محاسبه‌ی `percentile` (درصد کاربرانی که با حدس بیشتر/زمان بیشتر حل کردند) — گواه اجتماعی برای مودال نتیجه (Festinger, *Social Comparison*, 1954).
- لیدربورد سراسری روزانه + **حلقه‌ی دوستان** (`/circle`): ساخت با نام اختیاری، join با لینک، بورد روزانه‌ی اعضا. مقایسه با «افراد مشابه/آشنا» انگیزه‌ی قوی‌تری از غریبه‌هاست (Festinger 1954) — این مهم‌ترین فیچر اجتماعی است.
- دوئل ناهمزمان (`/duel`): ساخت با seed، ثبت نتیجه‌ی دو طرف، status. (UI مال AI-10 — تو فقط API.)

### ۳) اسکیمای D1 (در `migrations/0001_init.sql`)
جدول‌های `results`، `circles`, `circle_members`, `duels`, `duel_results` — ایندکس روی `(puzzle_number)` و `(circle_id, puzzle_number)`. **هیچ داده‌ی شخصی ذخیره نکن** (خط قرمز ۲۸): فقط anonId (UUID)، نام مستعار، اعداد بازی.

### ۴) سخت‌گیری‌های مهندسی
- همه‌ی پاسخ‌ها `{ ok, data?, error? }`؛ خطاها با کد معنادار؛ CORS برای دامنه‌ی اپ و localhost.
- **Rate limiting** ساده (per-anonId per-endpoint، با KV یا D1) — ضد اسپم لیدربورد.
- **ضد تقلب حداقلی:** نتیجه‌ی گزارش‌شده باید ممکن باشد (۱ ≤ guessCount ≤ ۶؛ durationMs ≥ ۵۰۰۰ برای برد؛ حداکثر ۱ نتیجه به‌ازای هر anonId+puzzleNumber — upsert نه insert تکراری). نمایش نام‌ها: sanitize + محدودیت طول + فیلتر واژه‌های نامناسب (لیست کوچک داخلی).
- تست: Vitest + `@cloudflare/vitest-pool-workers` یا شبیه‌ساز miniflare — پوشش ≥ ۸۰٪.

### ۵) مستندسازی برای کلاینت‌ها
`README.md` پکیجت: نمونه‌ی curl همه‌ی endpointها + نحوه‌ی اجرای لوکال (`wrangler dev --local`) تا AI-08/10/12 بتوانند mock دقیق بسازند.

### 💡 ایده‌های افزوده (مبنای علمی)
- **درصدک به‌جای رتبه‌ی خام برای اکثر کاربران** («از ۷۳٪ بازیکن‌ها بهتر بودی!»): در لیدربوردهای بزرگ، رتبه‌ی پایین انگیزه‌کُش است؛ درصدک قاب‌بندی مثبت می‌دهد (اثر قاب‌بندی — Tversky & Kahneman 1981).
- **لیدربورد حلقه حداکثر ۳۰ نفر:** گروه‌های کوچکِ آشنا، مشارکت را بیشینه می‌کنند (اندازه‌ی گروه‌های اجتماعی پایدار — Dunbar 1992، لایه‌ی ۱۵-۵۰).
- **snapshot روزانه‌ی آمار تجمیعی** (میانگین حدس، نرخ برد هر معما) در جدول جدا → منبع «آمار زنده‌ی بی‌اسپویلر» game-board و تحلیل سختی کلمات برای AI-02.
