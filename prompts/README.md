## نحوه‌ی استفاده (برای مدیر پروژه)

1. برای هر AI، **کل محتوای فایل پرامپت مربوطه** را کپی کنید و به‌عنوان اولین پیام به آن بدهید.
2. به هر AI دسترسی به ریپازیتوری `https://github.com/golshandvr-del/My-game` بدهید.
3. AIها می‌توانند **کاملاً موازی و هم‌زمان** شروع کنند — مسیرهای مالکیتشان ناهمپوشان است.
4. اگر AIای درخواست تغییر قرارداد داد (فایل RFC ساخت)، شما به‌عنوان مدیر پروژه در همان فایل RFC بخش «Decision: تأیید/رد» را بنویسید و کامیت کنید.
